MUENZER63 ⚡ WEB INSTALLER

Flash the firmware and set the device string of your Muenzer63 (pay phone Lightning ATM, ESP32) from the browser. Use Google Chrome or Microsoft Edge on a desktop computer.

1 – Flash firmware

  • Connect the ESP32 of the Muenzer63 to your computer via USB.
  • Leave the latest firmware version selected.
  • Press Flash and follow the instructions. Choose Erase device for a fresh install.
Your browser does not support installing on ESP devices. Use Google Chrome or Microsoft Edge. Not allowed on HTTP – open this page via HTTPS.

Without Erase device the stored device string is kept when you update the firmware.

2 – Connect

  • Close other programs that use the USB port (serial monitor, flash dialog).
  • Press Connect and select the serial port of the ESP32.
  • A device without a stored device string (fresh install) starts in config mode by itself and shows USB CONFIG MODE. The LED blinks in config mode.
  • A configured device keeps running when you connect. To change its configuration press Restart device, or hold the LED button while switching the Muenzer63 on.
❌ Not connected ❌ No config mode

3 – Configure

Read config loads the device string currently stored on the device.

Copy the complete string from the Fossa (or LNURLDevice) extension in LNbits: URL,secret,currency
